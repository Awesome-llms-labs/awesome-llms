# awesome-llms 🗺️

![ci](https://github.com/awesome-llms-labs/awesome-llms/actions/workflows/ci.yml/badge.svg)

The meta-index of the [Awesome-llms-labs](https://github.com/awesome-llms-labs) family — nineteen research-backed awesome-lists covering the LLM landscape, from frontier models to the infrastructure that runs them.

## The lists

## Machine-readable index

[`data/index.json`](data/index.json) is the canonical list of lists — name, repo, URL, description, and categories. Consume it directly if you're building tooling on top of the family.
